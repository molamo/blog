函式

  • function name 都是以小寫命名

我們也可以定義函式成擁有參數（parameters）的，這是函式簽名（signatures）中特殊的變數。當函式有參數時，你可以提供那些參數的確切數值。嚴格上來說，我們傳遞的數值會叫做引數（arguments）。但為了方便起見，通常大家不太會去在意兩者的區別。雖然函式定義時才叫參數，傳遞數值時叫做引數，但很多情況下都能被交換使用。

  • 用法 參數:型別
fn another_function(x: i32) { 
	println!("x 的數值為：{x}"); 
}

函式本體是由一系列的陳述式（statements）並在最後可以選擇加上表達式（expression）來組成。

  • 陳述式（Statements）是進行一些動作的指令，且不回傳任何數值。
  • 表達式（Expressions）則是計算並產生數值。可以回傳。結尾不會上分號
fn main(){
	let x = 5; // 陳述式
	
	let y = {
		let x= 3;
		x + 1
	}// 框框內就是表達式
	println!("y的數值為{y}");
}

函數回傳

  • -> 指定回傳型態
fn five() -> i32 {
	5
}

fn main(){
	let x = five();
	println!("x 的數值為 {x}");
}
  • 需傳入變數時
fn main(){
	let x = plus_one(5);
	println!("x 的數值為 {x}");
}
fn plus_one(x :i32) -> i32 {
	x + 1
}
