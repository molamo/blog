純量型別(Scarlar)

整數、浮點數、布林以及字元四種

整數(Integer)

  • 帶號(signed) :有負數
  • 非帶號(unsigned):沒有負數
  • 預設是i32
  • 整數溢位 => 有函數能除裡，第九章再認真看(?

浮點數(floating-point)

  • f32 與f64兩種，不給型別預設為 f64
  • 所有浮點數都是帶號(signed)
let x = 2.0; // f64 
let y: f32 = 3.0; // f32

布林

就布林...

字元

Rust 的 char 型別大小為四個位元組並表示為一個 Unicode 純量數值，這代表它能擁有的字元比 ASCII 還來的多。

複合型別(Compound)

元組or數組（tuples）和陣列（arrays）

Tuples

let tup: (i32, f64, u8) = (500, 6.4, 1);
  • 他剖 or 禿剖都有人發音，應該不影響學習ㄅ
  • 可以擁有不同型別的內容
  • 指定取得某個位置時，tup.0, tup.1 or tup.2，從0開始算
  • 透過模式配對(pattern matching)用 let 把 tuple 塞回 xyz三個數 => 解構(destructuring)
let tup = (500, 6.4, 1); 
let (x, y, z) = tup; 
println!("y 的數值為：{y}");
// y 的數值為：6.4

單元型別(Unit)

沒有任何數值的元組有一種特殊的名稱叫做單元型別（Unit），其數值與型別都寫作 ()，通常代表一個空的數值或空的回傳型別。表達式要是沒有回傳任何數值的話，它們就會隱式回傳單元型別。

Arrays

  • 型別須一致
  • i32 在此是每個元素的型別，在分號後面的數字 5 指的是此陣列有五個元素。
let a: [i32; 5] = [1, 2, 3, 4, 5];
  • 有5個元素，初始皆為3
let a = [3; 5];
//等於
let a = [3, 3, 3, 3, 3];
  • 取得元素內容，a[0]這樣的寫法
