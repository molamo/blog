也許開始新的學習

25 Aug 2024

今天看到河道上有朋友去看鬼才之道了，星期五偷懶沒出門的我，是不是該先搧自己兩巴掌，嗚嗚嗚

最近看的水管影片比起之前確實是比較多知識或是學習的影片了，像是現在旁邊正在播著 Rust 的教學影片，而且還是英文的!!!到底是學英文還是學 Rust 又是另外一回事了

Rust 這一兩年來蠻多人在討論跟學習的，讓我覺得自己是不是也該跟風一下，不過，我現在比起花時間學習這些內容，可能還比較喜歡花時間在看如何調整自己的資金調整(?

找到了一個從頭開始的教學影片，目前看起來好像還可以，是不是就這樣跟著學阿...
