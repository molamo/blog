Rust 工具之 cargo

下面這段取自官方文件:

Cargo 是 Rust 的建構系統與套件管理工具。大部分的 Rustaceans 都會用此工具來管理他們的專案，因為 Cargo 能幫你處理很多任務，像是建構你的程式碼、下載你程式碼所需要的依賴函式庫並建構它們。我們常簡稱程式碼所需要用到的函式庫為依賴（dependencies）。

  • cargo new project_name 起新 Rust 專案以及產生專案所需的簡單結構
  • cargo.toml 專案配置文件，採 TOML 格式
  • cargo build 建置專案
  • cargo run 建置並執行專案，常用
  • cargo check 確認專案可以順利建置，但無產出
  • 建置結果存在資料夾下的target/debug裡

Rust 工具之 rustfmt

  • 可以格式化程式碼的工具，避免多采多姿的程式碼長相
  • rustfmt filename.rs
