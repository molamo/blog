變數

  • 強型別，即使未給明確型別，建置時也會自動判斷型別
  • 分為可變與不可變(可不可重新給值)
let x = 5; // 不可用 x = 4 再給值
let mut y = 4; // 可用 y = 3  將 y assign為 3
  • 變數基本都是不可變 immutable為主

常數

  • const
  • 設定時，變數名稱完整都大寫，下底線，給予型別以及初始值
const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;
  • 不可再重新設定

遮蔽

  • Shadowing
  • 有點像函數裡自己又一個函數，在{}中的變數是不會影響外面的變數
fn main() {
    let x = 5;
    let x = x + 1;
    {
        let x = x * 2;
        println!("x 在內部範圍的數值為：{x}");
    }
    println!("x 的數值為：{x}");
}
